# Source Ingestion & Knowledge Distillation

Use this guide when turning raw feedback, bug reports, or playtest notes into structured wiki pages.

## Workflow
1. **Preserve Raw Source**: Save raw notes, playtest transcripts, or balance logs in `wiki/sources/<YYYY-MM-DD-topic>.md`.
2. **Extract Claims**: Identify concrete facts, bug reproductions, or proposed stat changes.
3. **Update Entity / System Pages**:
   - If enemy behavior changes, update `wiki/entities/enemies.md`.
   - If voxel drop rates change, update `wiki/entities/voxel_materials.md`.
4. **Log Changes**: Record a concise entry in `wiki/log.md`.
