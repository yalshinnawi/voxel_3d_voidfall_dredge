## 🧹 Automated Cleanup & Artifact Hygiene

To ensure the repository remains pristine and free from multi-megabyte duplicates:

1. **Auto-Clean Previews & Stale Captures**:
   ```bash
   python scripts/analyze_screenshots.py
   ```
   *Analyzes visual metrics and automatically removes temporary preview files in `screenshots/previews/`.*

2. **One-Command Full Workspace Cleanup**:
   ```bash
   python scripts/cleanup_test_artifacts.py
   ```
   *Purges temporary previews, enforces canonical screenshot filenames, and cleans untracked test dumps.*

3. **3D Reference Model Catalog**:
   - Master 3D character and creature models are stored separately in [`docs/models/`](file:///d:/Projects/voxel_3d_voidfall_dredge/docs/models/).
   - Under no circumstance should ad-hoc test frames or unmanaged duplicates be stored there.
