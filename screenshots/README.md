# Visual Testing & Screenshots (`screenshots/`)

This directory stores automated visual playthrough captures, contact sheet montages, and diagnostic luminance reports generated by the visual test harness ([`src/core/screenshot.hpp`](file:///d:/Projects/voxel_3d_voidfall_dredge/src/core/screenshot.hpp)).

---

## 🖼️ File Inventory

| File / Folder | Format | Description |
| :--- | :--- | :--- |
| `00_all_phases_montage.png` / `.jpg` | $1600 \times 675$ RGB | **Master 4x3 Contact Sheet**: Displays all 10 visual phases side-by-side with slot labels, timestamp banners, and health indicators. |
| `visual_report.txt` / `.json` | Text / JSON | Diagnostic report detailing mean luminance, non-black ratio, timestamp, and health status for each phase. |
| `01_main_menu.png` .. `10_mission_debrief.png` | $1600 \times 900$ PNG | Full-resolution master frames for each recorded gameplay phase. |
| `previews/` | $800 \times 450$ JPEG | Lightweight frame previews (~40KB each) stamped with in-image date/time banners. Auto-cleaned by `analyze_screenshots.py`. |

---

## 🔍 Fast Visual Verification Protocol

To inspect the visual test results without opening multiple large PNG files:

1. **Run Visual Diagnostics**:
   ```bash
   python scripts/analyze_screenshots.py
   ```
   *Runs in $<0.1\text{s}$, verifies that mean luminance $>0.02$ and non-black ratio $>15\%$, and auto-cleans temporary preview files.*

2. **Single-Glance Verification**:
   Inspect [`screenshots/00_all_phases_montage.jpg`](file:///d:/Projects/voxel_3d_voidfall_dredge/screenshots/00_all_phases_montage.jpg) or `.png` to view the entire playthrough in a single image.

3. **In-Game Screenshot Hotkey**:
   Pressing **`F12`** during active gameplay captures an instant timestamped frame to `screenshots/screenshot_YYYYMMDD_HHMMSS.png`.
