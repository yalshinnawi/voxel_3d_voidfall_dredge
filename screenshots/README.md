# Visual Testing & Screenshots (`screenshots/`)

This directory stores automated visual playthrough captures, contact sheet montages, diagnostic luminance reports, and procedural audio mastering samples generated by the engine's test harnesses.

---

## 🖼️ Canonical File Inventory

### 1. Gameplay Playthrough Suite (`--auto-play-test`)
| File | Format | Description |
| :--- | :--- | :--- |
| `00_all_phases_montage.jpg` / `.png` | $1600 \times 675$ RGB | **Master 4x3 Contact Sheet**: Displays all 10 gameplay screens + system telemetry + health card. |
| `visual_report.txt` / `.json` | Text / JSON | Luminance, non-black ratios, timestamps, and pass/fail status. |
| `01_main_menu.png` .. `10_mission_debrief.png` | $1600 \times 900$ PNG | Full-resolution master frames for each recorded phase. |

### 2. Void Stalker FSM Enemy Suite (`--test-enemy`)
| File | Format | Description |
| :--- | :--- | :--- |
| `enemy_visual_montage.jpg` / `.png` | $1200 \times 450$ RGB | **Master 3x2 Contact Sheet**: Floor crawl, wall climb, ceiling crawl, surface transition, lunge, stun. |
| `enemy_visual_report.txt` / `.json` | Text / JSON | Telemetry and health metrics for enemy visual tests. |
| `enemy_01_floor_crawl.png` .. `enemy_06_sonar_stun.png` | $1600 \times 900$ PNG | Individual high-res enemy animation frames. |

### 3. Procedural Audio Samples & Safety
| File / Folder | Format | Description |
| :--- | :--- | :--- |
| `audio_safety_report.json` | JSON | Validates mathematical peak limits ($\le -0.5\,\text{dBFS}$) and dynamic range. |
| `audio_samples/*.wav` | WAV | Reference audio render samples (drill, burrower, weapons, footsteps). |

## 🧹 Automated Cleanup & Artifact Hygiene

To ensure the repository remains pristine and free from multi-megabyte duplicates:

1. **Auto-Clean Previews & Stale Captures**:
   ```bash
   python scripts/analyze_screenshots.py
   ```
   *Analyzes visual metrics and automatically removes temporary preview files in `screenshots/previews/`.*

2. **One-Command Full Workspace Cleanup**:
   ```bash
   python scripts/cleanup_test_artifacts.py
   ```
   *Purges temporary previews, enforces canonical screenshot filenames, and cleans untracked test dumps.*

3. **3D Reference Model Catalog**:
   - Master 3D character and creature models are stored separately in [`docs/models/`](file:///d:/Projects/voxel_3d_voidfall_dredge/docs/models/).
   - Under no circumstance should ad-hoc test frames or unmanaged duplicates be stored there.
